សេចក្តីណែនាំដំបូងបង្អស់ ការរៀបចំ Git និង GitHub សម្រាប់អ្នកចាប់ផ្តើមដំបូង។
មុននឹងអ្នកអាចសរសេរ និងគ្រប់គ្រងកូដបាន
អ្នកត្រូវរៀបចំឧបករណ៍មូលដ្ឋានទាំងនេះជាមុនសិន។
ទីមួយ ការបង្កើតគណនី GitHub។
GitHub គឺជាកន្លែងផ្ទុកកូដរបស់អ្នកនៅលើអ៊ីនធឺណិត។
ចូលទៅកាន់គេហទំព័រ github dot com
ចុចពាក្យ Sign up នៅជ្រុងខាងស្តាំខាងលើ។
បំពេញអ៊ីមែល បង្កើតពាក្យសម្ងាត់ និងឈ្មោះអ្នកប្រើប្រាស់របស់អ្នក
រួចបញ្ជាក់អត្តសញ្ញាណតាមអ៊ីមែល ជាការស្រេច។
ទីពីរ ការដំឡើង Git លើកុំព្យូទ័រ។
អ្នកត្រូវដំឡើងកម្មវិធី Git នៅលើកុំព្យូទ័ររបស់អ្នក ដើម្បីអាចបញ្ជូនកូដបាន។
សម្រាប់ Windows ចូលទៅកាន់ git-scm dot com
ទាញយកកម្មវិធី ហើយចុច Next រហូតដល់ចប់។
សម្រាប់ Mac អ្នកអាចបើក Terminal ហើយវាយ git version
បើវាសួរឱ្យដំឡើង Developer Tools គឺចុច Install ជាការស្រេច។
បន្ទាប់ពីដំឡើងរួច បើក Terminal ឬ Git Bash
ហើយកំណត់អត្តសញ្ញាណដោយប្រើ git config user name និង user email។
ទីបី ភាពខុសគ្នារវាង HTTPS និង SSH។
ពេលអ្នកភ្ជាប់កូដពីកុំព្យូទ័រទៅ GitHub គឺមានពីររបៀបធំធំ។
HTTPS ងាយស្រួលប្រើពេលចាប់ផ្តើមដំបូង
ប៉ុន្តែរាល់ពេលដែលអ្នក Push កូដ វាទាមទារ Username និង Personal Access Token។
SSH មានសុវត្ថិភាពខ្ពស់ និងលឿនជាង។
វាប្រើប្រាស់គូសោ ឬ SSH Keys គឺ Public និង Private។
នៅពេលរៀបចំរួចរាល់ អ្នកអាច Push កូដបាន ដោយមិនបាច់វាយ Password ម្តងទៀតឡើយ។
ទីបួន ការបង្កើត SSH Key និងដាក់បញ្ចូលក្នុង GitHub។
ជំហានទី ក បង្កើត SSH Key ថ្មីក្នុងកុំព្យូទ័ររបស់អ្នក។
បើក Terminal ឬ Git Bash ហើយវាយ ssh-keygen ជាមួយអ៊ីមែលរបស់អ្នក។

តែអ្នកអាចគ្រាន់តែចុច Enter រហូតបាន។

រួច Copy អត្ថបទទាំងអស់ ចាប់ពី ssh រហូតដល់ចប់អ៊ីមែល។
