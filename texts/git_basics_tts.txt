សួស្តីបងប្អូនទាំងអស់គ្នា។
ថ្ងៃនេះ យើងនឹងរៀនពីការប្រើប្រាស់ Git ប្រចាំថ្ងៃ។
សេចក្តីណែនាំមូលដ្ឋានអំពី Git សម្រាប់អ្នកចាប់ផ្តើមដំបូង។
ការប្រើប្រាស់ Git មិនសាហាវដូចការគិតទេ។
ខាងក្រោមនេះគឺជា Commands មូលដ្ឋានសំខាន់សំខាន់
ដែលអ្នកត្រូវប្រើប្រាស់ជាប្រចាំថ្ងៃ។
ទីមួយ Setup និងកំណត់អត្តសញ្ញាណ។
មុននឹងចាប់ផ្តើម អ្នកត្រូវប្រាប់ Git ថាអ្នកជានរណា
ដោយប្រើ git config ដើម្បីកំណត់ user name
និង user email របស់អ្នក។
ទីពីរ ចាប់ផ្តើមប្រើ Git ក្នុង Project ដោយប្រើ git init។
ចូលទៅកាន់ Folder របស់អ្នកតាមរយៈ Terminal ឬ Command Prompt
រួចវាយពាក្យ git init។
វាបង្កើត Local Repository ថ្មី ក្នុង Folder នោះ។
ទីបី ការពិនិត្យស្ថានភាពកូដ ដោយប្រើ git status។
ដើម្បីដឹងថាមាន File ណាខ្លះបានកែប្រែ ឬទើបបន្ថែមថ្មី។
ទីបួន ជ្រើសរើស File ដាក់ចូល Staging Area ដោយប្រើ git add។
វាយ git add dot ដើម្បីជ្រើសរើស File ទាំងអស់ដែលបានកែប្រែ
ឬ git add រួចដាក់ឈ្មោះ File សម្រាប់ជ្រើសរើសតែ File ណាមួយ។
ទីប្រាំ ការរក្សាទុកការកែប្រែជាផ្លូវការ ដោយប្រើ git commit។
ដាក់ស្លាកសញ្ញា ឬកំណត់ចំណាំលើការកែប្រែនោះ
ដោយសរសេរពន្យល់ពីអ្វីដែលអ្នកបានកែប្រែ។
ទីប្រាំមួយ ការភ្ជាប់ទៅកាន់ GitHub ដោយប្រើ git remote add។
ដើម្បីភ្ជាប់ Project ក្នុងកុំព្យូទ័រ
ទៅកាន់ GitHub Repository របស់អ្នក។
ទីប្រាំពីរ ការបញ្ជូនកូដឡើងទៅ GitHub ដោយប្រើ git push។
git push origin main ឬ master អាស្រ័យលើឈ្មោះ Branch របស់អ្នក។
ទីប្រាំបី ការទាញយកកូដចុងក្រោយមកវិញ ដោយប្រើ git pull។
ប្រសិនបើអ្នកធ្វើការជាក្រុម ឬមានការកែប្រែពីកុំព្យូទ័រផ្សេង
វាយ git pull origin main។
សរុបមក អនុវត្ត commands ទាំងនេះជាញឹកញាប់
អ្នកនឹងមានភាពស្ទាត់ជំនាញក្នុងការប្រើប្រាស់ Git
សម្រាប់គ្រប់គ្រងកូដរបស់អ្នកយ៉ាងងាយស្រួល!
សង្ឃឹមថាមេរៀននេះមានប្រយោជន៍។
កុំភ្លេចចុចតាមដាន សម្រាប់មេរៀនបន្ទាប់។
